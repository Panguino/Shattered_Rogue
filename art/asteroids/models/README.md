# Runtime asteroid source models

These GLBs are the source-of-truth inputs for the Unreal runtime kit:

| Unreal mesh | Source | Original name | Size family |
| --- | --- | --- | --- |
| `SM_Asteroid_01` | `runtime_small_01.glb` | Big Astroid Small 1 | Small |
| `SM_Asteroid_02` | `runtime_small_02.glb` | Big Astroid Small 2 | Small |
| `SM_Asteroid_03` | `runtime_medium_01.glb` | Big Astroid Medium 1 | Medium |
| `SM_Asteroid_04` | `runtime_medium_02.glb` | Big Astroid Medium 2 | Medium |
| `SM_Asteroid_05` | `runtime_medium_03.glb` | Big Astroid Medium 3 | Medium |
| `SM_Asteroid_06` | `runtime_high_01.glb` | Big Astroid High 1 | High |
| `SM_Asteroid_07` | `runtime_high_02.glb` | Big Astroid High 2 | High |
| `SM_Asteroid_08` | `runtime_high_03.glb` | Big Astroid High 3 | High |

Numbering is a runtime contract: `ShatteredEnvironmentTypes.h` derives each family's
index range from contiguous blocks, so a new variant is inserted into its family and
the whole kit is re-exported rather than appended at the end.

Each source is roughly one metre across with one UV set and embedded 2K base
colour, normal, and roughness/metallic maps. They are watertight and correctly
wound; the ~1,500 open edges a topology check reports are UV seams, and welding
coincident vertices takes the count to zero.

Conversion and import:

1. Run `ShatteredRogue/Scripts/convert_asteroid_glbs.py` through Blender 5.1 in
   the table order. It recentres pivots and exports LOD0 and the textures only.
2. Run `ShatteredRogue/Scripts/import_asteroid_kit.py` through the full Unreal
   editor with `-ExecutePythonScript`. UE 5.8's Python commandlet silently
   no-ops the LOD APIs, so the full editor is required.

LODs are generated by Unreal, not Blender: collapse decimate cannot weld across
these UV seams, so each side of a seam reduces on its own and splits apart. The
import also clears `recompute_normals` on every LOD so the authored split
normals survive — otherwise Unreal rebuilds them per LOD from topology, seams
harden into facets, and the rocks look low-poly and shift appearance as levels
swap. Switch thresholds are set explicitly (1.0 / 0.09 / 0.025) because
auto-compute swapped far too early for objects this central to the frame.

Runtime selection is size-aware: Small-only through 1.4 scale, a Small/Medium
blend from 1.4–2.4, and Medium-only from 2.4 up to the 5.5 giant threshold. The
three High models are the authored **large asteroid** silhouettes and are
reserved for 5.5+ giants and the rare 14–24 colossal landmark. They never appear
on an ordinary middle-sized rock merely to add variety; seeing that model should
itself tell the player the body is genuinely huge.

The superseded ~470-triangle kit and its source GLBs live in
`archive/unreal-asteroids-2026-08-24-before-big-asteroids/`.
